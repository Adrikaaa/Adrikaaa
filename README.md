# 📌 Featured Projects

- **[VerifAI](https://github.com/Adrikaaa/verifai)** · *Diversion 2026 Hackathon*
  Deepfake / AI-content detection platform. I built the Next.js + TypeScript dashboard, the scan and extension API routes, and the Chrome extension for scanning videos in the browser.

- **[Project Management Web App](https://github.com/Adrikaaa/PROJECT-MANAGEMENT-WEB-APP)** · [Live demo](https://project-management-lyart-ten-69.vercel.app)
  MERN app for projects, tasks and notes. JWT auth in HTTP-only cookies, email verification with Nodemailer, protected routes. Deployed on Vercel + Render + MongoDB Atlas.

- **[Access + Refresh Token Auth](https://github.com/Adrikaaa/ACCESS-REFRESH-TOKEN-IMPLEMENTATION)**
  Short-lived access tokens plus long-lived refresh tokens (HTTP-only cookie, stored in the DB), with Node.js, MongoDB and a React client.

- **[Employee Management System](https://github.com/Adrikaaa/EmployeeManagemen)**
  Full CRUD with Java Servlets, JSP, JDBC and Oracle (group project).
